## 🚀 Como executar no seu Computador (Passo a Passo)

### 1. Pré-requisitos
Certifique-se de ter o **Node.js** (versão 18 ou superior) instalado em seu computador.
Se não tiver, baixe gratuitamente em: [nodejs.org](https://nodejs.org/)

### 2. Extrair os arquivos
Extraia o arquivo `.zip` em uma pasta de sua preferência (ex: no Desktop ou Documentos).

### 3. Abrir no Terminal / VS Code
Abra a pasta extraída no seu terminal ou editor de código preferido (como Visual Studio Code).

### 4. Instalar as dependências
Execute o comando abaixo no terminal:
```bash
npm install
```

### 5. Iniciar o aplicativo
Execute o comando:
```bash
npm run dev
```
O terminal exibirá o endereço local (geralmente `http://localhost:3000`).
Abra esse link no navegador Chrome, Edge ou Firefox para ver o seu aplicativo rodando!

---

## 📦 Como gerar a versão de produção (Build)
```bash
npm run build
```
Uma pasta `dist/` será criada com todos os arquivos estáticos otimizados, pronta para publicação.

## 🌐 Onde publicar gratuitamente na Web?
Você pode hospedar este aplicativo em poucos cliques em:
1. **Vercel** (vercel.com) - Basta conectar o repositório GitHub ou arrastar a pasta `dist`
2. **Netlify** (netlify.com)
3. **GitHub Pages**
4. **Firebase Hosting**

---

## 📲 Como transformar em APK (Android) ou App da Play Store
1. Publique o app na web (ex: Vercel)
2. Acesse o site gratuito **[PWABuilder.com](https://www.pwabuilder.com/)**
3. Insira a URL do seu aplicativo publicado
4. Clique em **"Build My PWA"** e selecione **"Android Package"** para baixar o arquivo APK ou pacote para a Google Play Store!
